## PolySub Translator 0.5.0

- zgodne karty AMD na Windows automatycznie przygotowują własne środowisko ROCm;
- dodano oficjalne ROCm 7.14.0 oraz PyTorch 2.12.0 z repozytorium AMD;
- RX 9070 XT jest rozpoznawany jako `gfx1201` i pobiera pakiet dla właściwej architektury;
- program korzysta z odizolowanego Python 3.12, bez zależności od systemowego Pythona;
- automat rozróżnia obsługiwane cele RX 9000, RX 7000, RDNA2, Radeon PRO i Ryzen;
- karta jest oznaczana jako gotowa dopiero po prawdziwym obliczeniu testowym na GPU;
- przerwane przygotowanie środowiska można automatycznie wznowić;
- wydanie nie tworzy nowej paczki portable.
