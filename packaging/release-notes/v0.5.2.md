## PolySub Translator 0.5.2

- naprawiono instalację PyTorch ROCm 7.14, aby nie blokowała wymaganego źródłowego pakietu
  `rocm-7.14.0.tar.gz` przez opcję `--only-binary`;
- nieukończone środowisko AMD jest automatycznie naprawiane przy uruchomieniu lub odświeżeniu
  listy sprzętu;
- skaner modeli przechwytuje `WinError 448` i inne błędy niedostępnych punktów instalacji,
  dowiązań oraz uszkodzonych snapshotów Hugging Face;
- wadliwy snapshot jest pomijany, a program nadal szuka kompletnej kopii modelu;
- nowe pobrania modeli na Windows używają trybu Hugging Face bez symlinków;
- diagnostyka cache trafia do `model-cache-diagnostics.log`;
- zachowano izolowanie właściwego Radeona od iGPU i prawdziwy test GPU.
